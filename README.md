# Portofolio Pribadi - Kholit

Website portofolio pribadi responsif yang dibuat sebagai tugas kuliah mahasiswa program studi Ilmu Komputer. Website ini menampilkan profil singkat, daftar keahlian, portofolio proyek, serta tautan kontak.

## Teknologi yang Digunakan

- **HTML5**: Struktur semantik dokumen web
- **CSS3**: Penataan gaya kustom, variabel CSS (CSS custom properties), tata letak Flexbox dan Grid yang responsif (Mobile-first)
- **JavaScript (Vanilla)**: Interaktivitas DOM, navigasi responsif, dan Intersection Observer API
- **Google Fonts**: Inter (teks utama) dan JetBrains Mono (aksen dan label)

## Cara Menjalankan Secara Lokal

Website ini dibangun murni menggunakan vanilla HTML, CSS, dan JavaScript tanpa membutuhkan build tool atau dependensi eksternal.

1. Unduh atau clone repositori ini ke komputer Anda:
   ```bash
   git clone <url-repositori>
   ```
2. Buka folder proyek.
3. Buka file `index.html` langsung di peramban web (browser) favorit Anda, baik dengan cara klik ganda file tersebut maupun menggunakan ekstensi lokal server (seperti Live Server).
